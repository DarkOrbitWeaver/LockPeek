Do not upload design mockups or the README banner as screenshots of the running app. No synthetic Word/Excel results or invented file associations. Capture actual WinUI screens after the final build is installed and visually checked. Use disposable data with neutral filenames; remove personal paths by choosing neutral test resources before capture, rather than painting over or altering app behavior.
